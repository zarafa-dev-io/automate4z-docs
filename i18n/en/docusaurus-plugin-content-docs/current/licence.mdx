# License — EULA model

automate4z is **proprietary** software, distributed under an **End User License Agreement (EULA)**. Downloading and using the `a4z` binary, the Studio and the documentation constitutes acceptance of the terms below.

In practice:

- **What you get**: a non-exclusive, non-transferable right to use the software for your internal needs — the full binary, every task and interface included, nothing crippled.
- **What the license does not allow**: redistributing the software, reselling it, embedding it in a commercial offering, or deriving a competing product from it.
- **Your workflows remain yours**: the YAML files, datasets, reports and any artifact produced with automate4z belong to you entirely, including after the license ends.
- **No telemetry**: the binary transmits no usage data; it works fully offline (air-gap).

For commercial terms (scope, duration, support), contact the publisher via [GitHub](https://github.com/zarafa-dev-io/automate4z).
