# Run history

The **Executions** tab lists the **persisted** runs (per workspace), most recent
first, **filterable** (workflow, status, trigger, id).

## Run detail

Selecting a run shows its **detail**: status, **RC**, duration, **parameters**,
trigger, and the list of **tasks** (status, RC, duration).

## Gantt chart

The detail includes a **timeline (Gantt)**: each task is a bar positioned by its
**start** and **duration**, colored by status. **Parallel tasks overlap**
faithfully, and the **offending task** is highlighted. For a running run, the
Gantt updates **live** with a **"now"** marker.

## Relaunch

From the detail, **Relaunch** reopens the workflow and **re-runs** it with the
recorded parameters.

---

## Resume after failure

For an **interrupted** run (failure, stop), Studio offers **"Resume from
&lt;task&gt;"** based on the persisted state: tasks that **already succeeded are not
replayed**, and live monitoring resumes. If the run is **not resumable** (already
succeeded, file gone, no successful task), the option is **disabled with an
explanation**.
