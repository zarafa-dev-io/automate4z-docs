# Workflow editor (Code mode)

**Code** mode shows the YAML editor on the left and the read-only **DAG view**
(execution graph) on the right.

## Editing

- **CodeMirror 6** with YAML highlighting, line numbers and folding.
- **`${secret:NAME}`** (amber) and **`${{ … }}`** (purple) references are
  highlighted to set them apart.
- **Ctrl/Cmd-S** saves. The write is **verbatim** (your comments, order and style
  are preserved). A **conflict detection** warns if the file changed on disk since
  it was opened (a **Reload / Overwrite** banner).

---

## Schema-driven autocomplete

The editor offers completions from the **binary's schema** (`a4z schema`):

- workflow keys and step keys,
- task types on `uses:`,
- fields on `with:` depending on the task.

## Validation & the "Problems" panel

The content is continuously validated (schema + DAG cycles + warnings for missing
secrets). Diagnostics appear **inline** (gutter) and in a clickable **Problems
panel** (jump to line). A **"✓ schema valid"** / **"✕ N error(s)"** indicator
summarizes the state.

## DAG view (read-only)

On the right, the **execution graph** shows the steps and their dependencies
(including the **implicit sequential dependency**: a step without `needs` depends
on the previous one). When the text becomes invalid, the **last valid graph** is
kept with an indication. During a run, each node reflects the task's **live
status**.

:::tip Visual editing
To **modify** the graph (add/remove tasks, draw dependencies), switch to
[No-code mode](./no-code).
:::
